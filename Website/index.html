What Nexus does

These are the core systems your server will actually use, all built in from day one.

🛡️

Moderation

Moderation is the backbone of any Discord server. Nexus provides a full moderation system where each infraction gets its own case number. Members can be banned even if they're not in the server, so they can't join later. Nexus always checks the role hierarchy before an infraction, so lower roles can't give infractions to higher ones.

kickbanmutewarnpurgecasesmyhistory
🚨

AutoMod

Works quietly in the background. It catches message spam, blocks known scam links, and can lock the whole server down automatically if it detects a raid. Every type has its own sensitivity, adjustable from 1 to 10.

automod setupautomod raidendautomods
🔐

Autoroles

Give new members a role automatically the moment they join, keep someone's roles intact if they leave and come back, or hand out a role that quietly removes itself once the time is up.

joinrolesrole persisttimed role
🎫

Tickets

Members open a private ticket channel with a single click. Staff can bring other people in or out, and close it once it's handled.

ticket setupticket panelticket close
📊

Stats

Find out who's actually active. Nexus tracks message and voice activity over the last 30 days and turns it into a graph, whether you're looking at one person, one channel, or the whole server. You can also see how many people joined or left, and which invite brought people in.

stats userstats channelstats serverstats membersstats invitestats top
📋

Logging

Nine separate logging categories, from messages and users to moderation actions and role changes, each one routable to its own channel so nothing gets lost in one giant feed.

loglogslogging ignore
🎮

Games

17 games are built right in, from trivia and blackjack to hangman, connect 4, and snake. One command pulls up the whole menu.

games

Up and running in a few minutes

No account, no dashboard to log into. Everything happens in Discord.

Add Nexus to your server

Use the invite button and pick the server you manage. Make sure Nexus's role sits above the roles it will need to manage.

Type -commands

It opens a menu with every command grouped by category, only visible to you.

Set up what you need

Start with a log channel, then switch on AutoMod or tickets when you're ready. The docs walk through each one.
