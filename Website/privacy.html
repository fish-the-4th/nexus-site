Privacy

What Nexus keeps, why it keeps it, how long it stays, and how to ask for it to be removed. Last updated 18 November 2026.

The short version. Nexus stores your server's settings, moderation records and a few small things for features like reminders and games. It does not store the text of your messages. Activity counts and join records are deleted after 30 days. Everything else stays until it's removed or the server's data is wiped.

What Nexus keeps

Nexus runs on Discord IDs. A user ID, role ID or channel ID is a long number that points to something on Discord. Nexus stores these numbers, and in a few places a name that was current at the time. Here is everything it stores, feature by feature.

What Nexus doesn't keep

  • The text of messages. Activity stats count messages, they don't save them. AutoMod reads a message as it arrives to check for spam and scam links, then moves on.
  • Direct messages. Nexus only answers three commands in DMs (-ping, -commands and -help). Nothing from those is saved.
  • Voice audio, files, images or attachments.
  • Emails, passwords or payment details. Nexus never asks for any of these.
  • IP addresses. The dashboard uses your IP address for a minute or two to stop people spamming it. It is held in memory only and never saved.
  • Who reacted to a giveaway. The list of entries lives on Discord.

Some features do put copies of messages into your server, because that is what they are for. If message logging is on, deleted and edited messages are posted to the log channel your staff chose. The starboard copies a starred message into its channel. Moderation reasons appear in case records. Those copies are Discord messages in your server, so your server's own rules and Discord's terms apply to them, not this page.

Where your data goes

Nexus doesn't send data to advertisers or data brokers, and nothing here is sold. A few services are involved in running it:

  • Discord. Nexus only sees what Discord gives to a bot in the servers it's in. Discord's own privacy policy covers everything on the platform.
  • Wispbyte. The bot and its database file run on a Wispbyte server.
  • Google Translate. When someone runs -translate, the text they typed in that command is sent to Google Translate to get the result. Nothing else is sent, and Nexus doesn't save it.
  • GitHub. The website you're reading is hosted on GitHub Pages.
  • Cloudflare. Traffic to the dashboard passes through Cloudflare, which keeps the connection encrypted and protects the bot's server.

Who can see it

  • Server staff can see what the commands show them: cases, notes, stats and logs. Notes and cases need permissions like Kick Members. Staff in one server can't see another server's data.
  • You can see your own moderation history in a server with -myhistory, or on your page in the dashboard. Both only ever show your own records, and the dashboard also shows your own activity stats.
  • Anyone in a server can see game stats for any user with -games stats, since they aren't tied to a server.
  • The Nexus developer can read the database, because it sits on the machine that runs the bot. It is used to run, fix and support the bot.

How long it's kept

  • 30 days: message activity, voice activity, and join and leave records. Older entries are deleted automatically.
  • Until it ends: timed roles, saved mutes, timed bans and reminders.
  • Until someone removes it: cases, staff notes and persistent roles.
  • Until a wipe: everything else tied to a server.
Removing Nexus from a server does not delete that server's data. Without a wipe, the data stays so that settings and cases are still there if Nexus is added back. Ask for a wipe if you want it gone.

Your options

Wipe a server's data

The server owner can ask for a full wipe in the support server. Requests are reviewed by hand and take two confirmations before anything is deleted. A wipe removes everything tied to that server: settings, cases, notes, roles, tickets, reminders, giveaways, activity and the rest. It can't be undone.

A wipe does not remove game stats, since those belong to a user and not a server. Wipes are handled by hand and aren't guaranteed, but you'll be told what happened.

Ask about your own data

If you want your game stats removed, or you want to know what Nexus holds about you, ask in the support server. Moderation records belong to the server that created them, so removing a case is usually a decision for that server's staff. Staff can delete a case themselves with -casedelete.

Turn things off

  • Run -automod setup [type] 0 to switch an AutoMod type off.
  • Use -log remove [type] to stop a kind of logging.
  • Stats start counting as soon as Nexus is in the server, and the only way to stop them is to remove Nexus. They never keep more than 30 days either way.

The website

Apart from the dashboard, this site is static. It has no forms or comments, doesn't run analytics, and loads no scripts from other sites. The pages fetch a few small data files (the command list, status, staff and changelog) from the same place they are hosted. GitHub, which hosts the site, may keep ordinary server logs under its own policy.

Links to Discord, Top.gg and the support server take you to those sites, and they follow their own privacy policies.

The dashboard

The dashboard is the one part of the site with a login. When you log in with Discord, Nexus only asks for your user ID, username and avatar. It never sees your password, email or server list. Discord's login token is thrown away straight after, so Nexus can't act as you.

  • Your user ID, name and avatar are kept in the bot's memory while you're logged in, for up to 8 hours. They are never written to the database, and a bot restart clears them.
  • Your browser keeps a random login key in session storage until you log out or close the tab. It is not a cookie and isn't shared with other sites.
  • Every member can open their own page for a server they share with Nexus. It shows their profile, their activity stats and their own moderation history, and never anyone else's.
  • Only the server owner and members with the Administrator permission can open the admin side. Every change is checked against those permissions, and saved in the dashboard changes record shown above.

Security

The bot's token is kept out of the code and set as a secret on the host. The database is a single file on the host. No system is perfectly secure, and Nexus is run by one person, so there are limits to what it can promise. If you think something is wrong, tell the team in the support server straight away.

Age

Nexus runs on Discord, and Discord sets the minimum age for using it. Nexus doesn't ask for anyone's age and doesn't knowingly collect more than Discord already provides to a bot.

Changes to this page

If what Nexus stores changes, this page changes with it and the date at the top is updated. Meaningful changes are also listed in the changelog.
