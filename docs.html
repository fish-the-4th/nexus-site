Getting started

Nexus works with text commands. The default prefix is -, and you can also mention the bot instead (for example @Nexus ping), which always works even if you forget the prefix.

  1. Add Nexus with the invite button, and choose your server.
  2. Check the role order. In Server Settings, Roles, drag the Nexus role above any role it needs to manage (see Permissions and roles).
  3. Type -commands. A menu appears with every category. Only you can see the results when you press a button.
  4. Pick a log channel with -log moderation #your-channel, then turn on whatever else you want.
Add Nexus Ask in the support server
Changing the prefix: use -prefix set [prefix] (needs Manage Server). Use -prefix any time to see the current one.

Permissions and roles

Discord decides what a bot can do based on its permissions and where its role sits in the role list. Two things cause most problems:

  • Nexus can only act on roles below its own. If it needs to ban, mute, or hand out a role, its role has to be higher than the target's highest role, or higher than the role you're giving.
  • You can only use Nexus on people below you. Moderators can't kick, ban, mute or role someone who has the same or a higher role than they do. The server owner is exempt.

When Nexus can't do something because of the role order, it says so in the channel instead of failing quietly.

Each command lists the permission you need to use it. The server owner and administrators can always use them.

Guide: Moderation

Every action (kick, ban, mute, warn) creates a numbered case and sends the member a DM with the reason. You can find a case again later with -caseinfo [number] or see everything for someone with -cases [user].

Banning and muting

  • -ban [user or ID] [duration] [reason]. The duration is optional (7d, 12h). With no duration, the ban is permanent. It works on people who aren't in the server, as long as you have their ID. Their messages are not deleted.
  • -mute [user or ID] [minutes] [reason] uses Discord's timeout, from 1 minute up to 28 days (40320 minutes). If the person isn't in the server yet, the mute is saved and applies when they join.
  • -unmute removes a timeout, or cancels a saved mute. -unban [user_id/username] lifts a ban.

Warnings, cases and history

  • -warn [user] [reason] logs a warning. -unwarn removes one.
  • -casedelete [number] voids a case (needs Ban Members).
  • -myhistory lets any member get their own moderation history sent to their DMs. They can't see anyone else's.
Heads up: kick, warn and unwarn still need the person to be in the server. Case numbers and history are kept per server, so one server never sees another's cases.

Cleaning up

-purge [user] [amount] deletes recent messages from one person. Discord doesn't allow bots to bulk delete messages older than 14 days. Use -lock and -unlock to close and reopen a channel, -locked to list locked channels, and -slowmode [seconds] to slow a chat down.

Guide: AutoMod

AutoMod protects your server without anyone having to be online. There are three types:

  • spam catches people flooding messages.
  • scam blocks known scam links.
  • raids detects a sudden wave of joins and can lock the server down.

Turn a type on with -automod setup [type] [level]. The level goes from 1 to 10, and 0 turns that type off. For example, -automod setup spam 5. A middle value is a good place to start, and you can adjust from there.

  • -automod logging #channel picks where AutoMod reports what it did.
  • -automod whitelist add @user (or a role) exempts trusted people. whitelist remove undoes it.
  • -automods shows your current settings at a glance.
  • -automod raidend ends a raid lockdown and unlocks all channels once things calm down.

All of these need Manage Server.

Guide: Logging

Logging is split into categories so you can send each kind of event to its own channel. Use -log [type] [#channel] to turn one on. The types are:

messages users expressions channels voice moderation invites applications roles

  • -log remove [type] turns a category off.
  • -logs shows every category and where it goes.
  • -logging ignore add [user] stops logging someone, and ignore remove brings them back.

All of these need Manage Server. Make sure Nexus can see and send messages in the channels you pick.

Guide: Tickets

  1. Create a category for tickets and a channel for ticket logs.
  2. Run -ticket setup [support role] [category] [log channel] (needs Administrator).
  3. Run -ticket panel in the channel where members should open tickets. Nexus posts a message with a button.
  4. A member presses the button and gets a private channel with your support role.
  5. Staff can use -ticket add [user] and -ticket remove [user] inside a ticket, and anyone in the ticket can run -ticket close when it's done.

Guide: Autoroles and timed roles

Join roles

-joinroles set [role1] [role2]... gives those roles to everyone who joins. -joinroles shows them and -joinroles remove clears them.

Persistent roles

A persistent role comes back if the person leaves and rejoins. Use -role persist add [user] [role] to set one, and -role persist remove to undo it.

Timed roles

A timed role removes itself after a set time.

  • -timed role add [user] [duration] [role], for example -timed role add @John 2h @Event
  • -timed role remove [user] [role] to end it early
  • -timed roles [user] to see what someone has

See time formats for the duration. These commands need Manage Roles, and Nexus must be above the role it hands out.

Guide: Stats

Nexus counts messages and voice time for the last 30 days, then turns them into graphs. Stats start from the moment Nexus joins your server, so a brand new install will look empty at first.

  • -stats user [user] and -stats channel [channel] for one person or one channel.
  • -stats server shows total messages and voice hours for everyone.
  • -stats members shows how many people joined and left.
  • -stats top shows the top members and channels.
  • -stats invite [code] shows who created an invite, when, and how many people joined through it. It only works for invites to the server you run it in.

The invite and member graphs only include joins and leaves Nexus has seen since it arrived.

Time formats

Anywhere Nexus asks for a duration, you can combine numbers and letters.

  • m minutes, h hours, d days, w weeks, mon months, y years
  • Examples: 30m, 2h, 3d, 1w, 2mon, 1y
  • Reminders also accept combinations like 1h30m
  • -mute is the exception. It takes a plain number of minutes.

FAQ

Why does Nexus say "slow down"?

To keep the bot fast for everyone, you can't run two commands within about 2 seconds of each other, or repeat the same command within about 3 seconds. Wait a moment and try again.

Why can't I use commands in a DM?

Commands only work in servers, so Nexus knows which server you mean. The exceptions are -ping, -commands and -help. The one thing Nexus does send you in DMs is your own moderation history when you run -myhistory in a server.

What permissions does Nexus need?

It needs to read and send messages, and depending on what you use: Ban Members, Kick Members, Moderate Members, Manage Roles, Manage Channels, Manage Messages and Manage Server (to see invites for invite stats). The invite link asks for Administrator so every feature works without any permission puzzles. If you'd rather give it less, you can edit its permissions after it joins, but features that need a missing permission will tell you.

Can I change the prefix?

Yes, with -prefix set [prefix] if you have Manage Server. If anyone forgets it, mentioning the bot works as a prefix too.

Why is my graph empty?

Stats only count activity from when Nexus joined your server, and they only keep the last 30 days. Give it some time, and check that Nexus can see the channels you're asking about.

How do I report a bug or suggest something?

Join the support server and post it there.

Troubleshooting

Nexus isn't responding

  • Check the status page first.
  • Make sure Nexus can view and send messages in that channel.
  • Try @Nexus ping in case the prefix was changed.
  • If you just ran a command, wait 2 or 3 seconds and try again.

"I can't do that" or a role error

Almost always the role order. Move the Nexus role above the roles it needs to manage, and above the person you're acting on. See Permissions and roles.

A member says they got no DM

Nexus can't DM people who have server DMs turned off. The action still goes through and the case is still logged.

Still stuck?

Ask in the support server and include what you typed and what Nexus said back.
